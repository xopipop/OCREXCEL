# Быстрый старт

## За 5 минут к работе

### 1. Установка Python зависимостей

```bash
setup_env.bat
```

Или вручную:
```bash
pip install -r requirements.txt
python chandra_excel_com.py --register
```

### 2. Настройка API ключа

Создайте файл `.env` в корне проекта:
```bash
copy env.example .env
```

Откройте `.env` и укажите ваш ключ OpenRouter:
```
OPENROUTER_API_KEY=sk-or-v1-ваш-ключ-здесь
```

### 3. Настройка Excel

1. Откройте Excel, нажмите `Alt+F11`
2. Insert → Module
3. Скопируйте содержимое `INSTALLER.vba` в модуль
4. Запустите макрос `InstallChandraOCR` (Alt+F8 → InstallChandraOCR → Выполнить)
5. Дождитесь завершения установки
6. Сохраните как `ChandraOCR.xlsm`

**Готово!** Все модули созданы автоматически.

### 4. Назначьте горячую клавишу

1. `Alt+F8`
2. Выберите `ShowChandraForm`
3. Нажмите "Параметры"
4. Выберите `Ctrl+Shift+C` (или другое)

### 5. Использование

1. Нажмите `Ctrl+Shift+C` в Excel
2. Выберите PDF файл
3. Выберите шаблон (например, "Счет-фактура")
4. Укажите начальную ячейку (например, A5)
5. Нажмите ОК
6. Дождитесь обработки

**Готово!** Данные появятся в Excel.

## Примеры использования

### Обработка счета-фактуры

1. Шаблон: "Счет-фактура"
2. Начальная ячейка: A5
3. Результат: номер, дата, поставщик, покупатель, суммы

### Обработка договора

1. Шаблон: "Договор"
2. Начальная ячейка: B3
3. Результат: номер договора, даты, стороны, суммы

### Кастомная обработка

1. Не выбирайте шаблон
2. Введите свой промпт:
   ```
   Извлеки данные в JSON: {"поле": "значение"}
   ```
3. GPT вернет кастомную структуру
