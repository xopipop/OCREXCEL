# Chandra Excel Integration 📄✨

Автоматизируйте извлечение данных из PDF-документов и изображений прямо в Excel с помощью искусственного интеллекта.

Этот инструмент превращает рутинную задачу копирования информации из счетов, актов или договоров в один клик. Вы просто выбираете файл, а нейросеть сама находит и записывает нужные данные в вашу таблицу.

![Пример работы](https-ibb-co-Rg115qQ.gif)

## Как это работает?

Программа интегрируется с Microsoft Excel и использует мощную технологию **Chandra OCR** для распознавания текста, а затем отправляет его нейросетям (например, **GPT-4o**) для интеллектуального извлечения данных.

**Архитектура:** `Excel (VBA)` → `Python (COM)` → `Chandra OCR` → `AI (OpenRouter)` → `Excel`

## Начало работы: 3 простых шага

Чтобы все заработало, нужно один раз настроить окружение. Это займет не более 10-15 минут.

---

### Шаг 1: Настройка Python

Нам понадобится Python для работы с нейросетями.

1.  **Установите Python.**
    *   Скачайте установщик с [официального сайта Python](https://www.python.org/downloads/). Рекомендуется версия **3.10** или **3.11**.
    *   **Важно:** Во время установки обязательно поставьте галочку **"Add Python to PATH"**.

    ![Add Python to PATH](https://i.imgur.com/f2s1b9n.png)

2.  **Установите зависимости.**
    *   Откройте **Командную строку** (нажмите Win+R, введите `cmd` и нажмите Enter).
    *   Перейдите в папку с этим проектом с помощью команды `cd`. *Пример: `cd C:\Users\ВашеИмя\Downloads\chandra-master`*
    *   Выполните команду ниже, чтобы установить все необходимые библиотеки:
      ```bash
      pip install -r requirements.txt
      ```

3.  **Настройте API-ключ.**
    *   Зарегистрируйтесь на [OpenRouter.ai](https://openrouter.ai/), чтобы получить бесплатный доступ к различным нейросетям.
    *   Скопируйте ваш API-ключ.
    *   Выполните в **Командной строке** следующие две команды, подставив свой ключ:

      ```cmd
      setx OPENROUTER_API_KEY "sk-or-v1-ваш-ключ"
      setx OPENROUTER_MODEL "openai/gpt-4o"
      ```
    *   **Перезапустите Командную строку**, чтобы переменные применились.

---

### Шаг 2: Регистрация COM-сервера

Этот шаг позволяет Excel "общаться" с Python.

1.  Снова откройте **Командную строку**, но на этот раз **от имени администратора**.
2.  Перейдите в папку с проектом (`cd C:\...`).
3.  Выполните команду:
    ```bash
    python chandra_excel_com.py --register
    ```
    Если вы увидите сообщение "Registered successfully", значит, все прошло отлично.

---

### Шаг 3: Настройка Excel

Остался последний шаг — добавить кнопку в Excel.

1.  **Откройте Excel** и создайте новую пустую книгу.
2.  **Откройте редактор VBA**, нажав `Alt+F11`.
3.  **Вставьте код установщика:**
    *   В редакторе VBA кликните правой кнопкой мыши на `ThisWorkbook` -> `Insert` -> `Module`.
    *   Откройте файл `INSTALLER.vba` в любом текстовом редакторе (например, в Блокноте).
    *   Скопируйте **все содержимое** файла и вставьте его в созданный пустой модуль в Excel.
4.  **Запустите установщик:**
    *   Нажмите `Alt+F8`, чтобы открыть список макросов.
    *   Выберите `InstallChandraOCR` и нажмите **"Выполнить"**.
    *   Дождитесь сообщения об успешной установке. Все необходимые модули и формы будут созданы автоматически.
5.  **Сохраните книгу** как файл с поддержкой макросов (`.xlsm`).

Поздравляем, все готово! 🎉

## Как пользоваться

1.  **Откройте вашу `.xlsm` книгу.**
2.  Нажмите `Alt+F8`, выберите `ShowChandraForm` и нажмите "Выполнить".
    *   **Совет:** Для удобства назначьте на этот макрос горячую клавишу (в окне макросов кнопка "Параметры").
3.  **В открывшейся форме:**
    *   **Выберите PDF-файл** или изображение.
    *   **Выберите готовый шаблон** (например, "Счет-фактура") или оставьте поле пустым и **напишите свой запрос** к нейросети.
    *   **Укажите ячейку**, с которой начнется запись данных.
4.  Нажмите **"Запуск"** и наблюдайте за магией!

## Шаблоны

Вы можете добавлять свои собственные шаблоны для извлечения данных, отредактировав файл `templates_config.json`.

**Пример шаблона:**
```json
{
  "templates": {
    "Мой шаблон": {
      "prompt": "Извлеки из текста номер заказа и сумму. Верни JSON с полями 'order_id' и 'total_amount'.",
      "fields": ["order_id", "total_amount"]
    }
  }
}
```
- `prompt` — это инструкция для нейросети.
- `fields` — поля, которые будут записаны в Excel.

## Устранение неполадок

*   **Ошибка "COM-сервер не зарегистрирован"**:
    *   Убедитесь, что вы запустили команду `python chandra_excel_com.py --register` в **Командной строке от имени администратора**.

*   **Ошибка "Не удалось получить доступ к проекту VBA"**:
    *   В Excel перейдите: `Файл` -> `Параметры` -> `Центр управления безопасностью` -> `Параметры центра...` -> `Параметры макросов` и поставьте галочку **"Доверять доступ к объектной модели проектов VBA"**.

*   **Медленная работа**:
    *   Первый запуск может быть долгим, так как модели загружаются в память. Последующие запуски будут быстрее. Для максимальной скорости рекомендуется использовать GPU от NVIDIA.
